Usage Rules

Maintain consistency across all touchpoints. These guidelines ensure the brand remains premium and trustworthy.

Do
  • Use the navy gradient for hero sections and primary CTAs
  • Reserve Playfair Display for hero taglines only
  • Use steel blue as the primary accent for interactive elements
  • Use silver for badges, tags, and soft highlights
  • Maintain generous whitespace between sections
  • Use navy-tinted shadows (not pure black)
  • Keep body text in Inter at 16px for readability
Don't
  • Don't use Playfair Display for body text or small labels
  • Don't introduce off-brand colors (green, purple, orange, pink)
  • Don't use pure black (#000) for text — use Gray 900 (#0f172a)
  • Don't apply the accent gradient to large background areas
  • Don't use more than two gradients on a single page
  • Don't mix navy shades inconsistently — pick one per element
  • Don't use font weights below 400 for any visible text
